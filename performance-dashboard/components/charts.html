Chart presentations · 6 styles

Power curve data (5s → 60m) shown six ways. Match chart type to the metric story — curve shape, comparison, or profile.

Chart 01
Dual area line
Current 28d vs previous 28d with filled areas. Default for power curve delta.
Power curvePace curve

Best for: Power curve delta, pace-duration profile, any current-vs-previous window comparison.

Chart 02
Vertical bar anchors
MMP or best pace at each duration as bars. Easy to read absolute watts/pace per anchor.
MMP anchorsSustainability table alt

Best for: Sustainability profile anchors, swim distance bests, erg duration peaks.

Chart 03
Gradient line (no fill)
Clean single-series line with colour gradient. Minimal chart noise.
Minimal layoutsCTL trend

Best for: V5 Minimal Pro, single-metric trends (CTL, FTP history, weekly km).

Chart 04
Radar / spider profile
Energy-system shape at a glance — sprint vs endurance bias visible as polygon shape.
Rotation indexMulti-anchor

Best for: Power curve shape, tri sport balance, comparing athlete profile to target polygon.

Chart 05
Horizontal bar + target line
Ranked metrics with dashed target marker. Good for race estimation rows.
70.3 legsBlock goals

Best for: Sustainability vs target (20m/60m/90m), tri leg targets, benchmark vs actual list.

Chart 06
Stepped block / histogram
Duration buckets as blocks — emphasises time-in-zone or load distribution.
TID zonesWeekly TSS

Best for: Seiler zone time distribution, weekly load histogram, vert per day blocks.
