Ring & gauge presentations · 6 styles

Same metrics (FTP 258W, AeT 195W, CTL 78) in each style. Pick one ring type per hero metric on your Performance tab.

Ring 01
Classic arc ring
Single stroke, open center. Clean and familiar — matches wellness Recovery/Strain rings.
FTPAeTCTL

Best for: Primary thresholds (FTP, threshold pace, CSS). Hero row at top of Performance tab.

Ring 02
Zone-segment donut
Ring split into green / amber / red zones. Shows where current value sits in training range.
Readiness bandsBenchmark zone

Best for: Metrics with clear target bands — CTL vs phase target, weekly volume vs plan, easy-time ratio.

Ring 03
Dual ring — target vs actual
Outer ring = goal/dossier value. Inner ring = current measured value. Gap visible at a glance.
FTP vs goalDFA vs dossier

Best for: Calibration deltas — AeT estimate vs dossier FTP, CSS vs race target, benchmark index vs seasonal band.

Ring 04
Semi-circle gauge
Speedometer layout. Strong single-metric focus — less suited to a row of four equals.
Single heroMobile

Best for: One headline metric per screen — mobile Performance tab, or FTP as the only giant number.

Ring 05
Neon glow ring
Thick stroke with glow. High-end / gaming aesthetic. Use sparingly (1–2 metrics max).
Premium feelAccent only

Best for: Highlighting the one metric that improved most this block — or race-week FTP freshness.

Ring 06
Minimal tick ring
Thin arc + tick marks, Apple Watch aesthetic. Quiet, precise, pairs with Minimal Pro layout (V5).
Minimal UISecondary metrics

Best for: Secondary thresholds (LTHR, W′, weekly km) when FTP uses a larger hero treatment elsewhere.
